# Report source

LaTeX source of the project report, kept under version control so that the
document and the code that produced its figures stay in sync. The figures in
`assets/` are copies of the ones in `results/figures/`, regenerated by
`scripts/make_figures.py`, and the numbers in the text are checked against
`results/benchmark.csv` by `tests/test_reported_numbers.py`.

Build with any pdfTeX toolchain:

```bash
cd docs/report
latexmk -pdf main.tex
```

`main.tex` pulls in one file per section (`summary`, `introduction`, `models`
which in turn includes `dcgan` and `vae`, `algorithm`, `mnist`, `results`,
`conclusions`) and closes with the bibliography in `references.bib`. Figures
live in `assets/`.
